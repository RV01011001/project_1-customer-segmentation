# Project 1 - Customer Segmentation

![Customer Segmentation](img/Readme_title.png)

## Overview

The work on this project was carried out using a transactional data set. This set contains all transactions that took place between 01/12/2010 and 09/12/2011 for a UK-based and registered non-store online retailer. The company specialises in unique gifts for all occasions. A significant proportion of the company's client base consists of wholesalers.

## Goal

Segment customers into distinct groups based on behavioral and demographic data to enable targeted marketing strategies.


## Objectives
1. Define the Problem & Goals
2. Data Collection & Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Selection & Engineering
5. Unsupervised Learning – Clustering
6. Analyze Cluster Profiles

## Project Structure

- data
    - processed
        - e-commerce-data-canceled.csv - *a dataset from which records of cancelled orders have been removed*
        - e-commerce-data-cleaned.csv - *a finalized dataset after all cleaning procedures at stage 2*
    - raw
        - e-commerce-data-raw.csv - *original data set*
- notebooks
    - 01_define_the_problem_and_goals.ipynb - *the Jupiter notebook, which contains a description of the project, its main objective, and the results to be achieved*
